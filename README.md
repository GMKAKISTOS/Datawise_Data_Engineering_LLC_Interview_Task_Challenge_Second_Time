What This Project Does

The project contains a schema validation task implemented with Python.

The basic process is:

Input Data
    ↓
Schema Validation
    ↓
Python Application
    ↓
Tests
    ↓
Successful Result


The application checks the provided data against the required schema and verifies that the expected tests are successfully completed.
